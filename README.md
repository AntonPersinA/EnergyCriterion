# EnergyCriterion

Репозиторий с реализациями методов на основе энергетического критерия
и Randomly Projected Energy Statistics (RPES) для задач высокой размерности.

## 📂 Структура проекта

### EnergyCriterion
Реализация подсчёта мощности энергетического критерия:

- [6_highdim_Cauchy_g_omp](https://github.com/AntonPersinA/EnergyCriterion/tree/main/6_highdim_Cauchy_g_omp) —
  реализация для многомерного случая.

### RPES
Реализация RPES:

- [6_random_project](https://github.com/AntonPersinA/EnergyCriterion/tree/main/6_random_project) —
  базовая реализация RPES.
- [6_random_project_gamma](https://github.com/AntonPersinA/EnergyCriterion/tree/main/6_random_project_gamma) —
  реализация RPES с гамма распределение.
